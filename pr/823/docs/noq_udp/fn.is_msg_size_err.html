pub fn is_msg_size_err(err: &Error) -> bool

Returns true if the given I/O error corresponds to a message size error

Useful, for example, after invoking io::Error::last_os_error() to check if the last OS error was a message size error (EMSGSIZE on Unix, WSAEMSGSIZE on Windows).

Note: EMSGSIZE’s value is not standardized across OSes (90 on Linux, 40 on macOS/iOS/BSD; on Windows, io::Error::raw_os_error() returns the Winsock error WSAEMSGSIZE (10040) via GetLastError(), which is distinct from the MSVCRT errno.h EMSGSIZE value of 115, which is never actually populated by socket operations).
