Expand description

Abstract implementation of a UDP socket of an endpoint with multiple sockets

Unlike AsyncUdpSocket, receiving is split off into UdpReceivers, so the socket itself can be shared: the endpoint keeps it to create senders, and each receiver is polled by its own task.

fn create_receiver(&self) -> Option<Box<dyn UdpReceiver>>

Create a receiver for this socket, or None if it can’t create more

The endpoint calls this up to max_receivers times when the socket is added, and stops at the first None. Each receiver is polled by its own task.
