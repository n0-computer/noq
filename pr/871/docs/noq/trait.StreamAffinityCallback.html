fn affinity(&self, ctx: StreamAffinityContext) -> StreamAffinity

Sets the affinity for a single stream.

This function must not block.

The provided StreamAffinityContext gives some information about the connection and stream the callback is being invoked for as well as the current paths available right now.

The desired affinity for the stream should be returned by an instance of the StreamAffinity struct. This struct can be created directly using one of the public constructors.
